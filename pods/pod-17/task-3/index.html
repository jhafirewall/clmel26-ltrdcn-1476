    Task 3: Attach and Deploy the networks

    Task 3: Attach and Deploy the networks

    Objective

    Attach vlan43 to Smart-SW-1 Ethernet1/13 and vlan44 to Smart-SW-2 Ethernet1/13, following the supplied host-to-switch design. This guide deploys the VRF first, then the two networks.

    Attach the networks

    1. Attach vlan43 to Smart-SW-1 Ethernet1/13.

      • a. In SmartSwitch-Pod1, open Segmentation and security > Networks.

      • b. Click vlan43, then click Network Attachments.

      • c. Select the check box which has an entry of Smart-SW-1 switch, then click white Actions > Edit

      • d. In the Edit Network Attachment screen, click the slider to Attach, then under Attached interface for this device click (white) Action and click on Add network interface attachment

        Figure. Network attachment editor for vlan43.

      • e. Under Add Network Interface Attachment, filter with Smart-SW-1 and Ethernet 1/13

        Figure. Select Smart-SW-1 Ethernet1/13 for vlan43.

        Figure. Selected interface for the vlan43 attachment.

      • f. Click Add, then Save the attachment.

        Figure. vlan43 interface attachment in the edit view.

      • g. Return to the Networks view

        Figure. vlan43 attached to Smart-SW-1.

    2. Attach vlan44 to Smart-SW-2 Ethernet1/13.

      • a. Click vlan44, then open Network Attachments tab.

      • b. Select the check box which has an entry of Smart-SW-2 switch then click white Actions > Edit.

      • c. In the Edit Network Attachment screen, click the slider to Attach then under Attached interface for this device click (white) Action and click on Add network interface attachment.

      • d. Under Add Network Interface Attachment, filter with Smart-SW-2 and Ethernet 1/13

      • e. Click Add and then click Save

        Figure. vlan44 attachment for Smart-SW-2.

      • f. Return to the Networks view

        Figure. Network table after attachments are staged.

    Both network attachments are staged in Nexus Dashboard. Deploy the VRF first, then deploy the networks.

    Deploy the VRF

    1. Open Segmentation and security > VRFs.

    2. Select labusr17-vrf, then choose Actions (white) > Deploy.

    Figure. VRF deployment action.

    Figure. Pending VRF configuration review.

    1. Review the pending configuration, click Deploy, and once the status is green click on Close.

    Figure. VRF deployment status.

    1. You will see the vrf labusr17-vrf is deployed, ensure it has a Deployed status

    Figure. labusr17-vrf is deployed.

    Deploy the networks

    After the VRF is deployed, deploy both network configurations.

    1. Open Segmentation and security > Networks.

    2. Select vlan43 and vlan44, then choose Actions (white) > Deploy.

    Figure. Pending network configuration review.

    1. Review the pending configuration, click Deploy, and select when it gets completed, click Close.

    Checkpoint

    Checkpoint: Confirm that both networks show Deployed and that each attachment is Attached to the expected switch and its interface. The recording showed successful configuration synchronization.

    Figure. Both networks show Deployed.
